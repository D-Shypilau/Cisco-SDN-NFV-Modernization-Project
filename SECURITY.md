# Security Policy

This repository contains an educational network-engineering laboratory and public portfolio artifacts.

## Sensitive material

Do not commit:

- passwords or password hashes intended for active systems;
- API tokens or session cookies;
- private keys or certificates containing private key material;
- real production IP addressing or confidential customer data;
- proprietary Cisco software images.

Configuration examples and lab snapshots must be reviewed and sanitized before publication.

## Reporting a problem

If you find a credential, secret, private key or other sensitive value in the repository, do not reuse or redistribute it. Report the exact file/path privately to the repository owner so it can be removed and, where applicable, rotated.

## Scope

The project is intended for education, research and authorized laboratory use only. It is not a production deployment guide and should not be applied to networks without independent validation and authorization.
