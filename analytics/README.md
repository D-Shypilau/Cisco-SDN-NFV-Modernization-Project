# Case-Study Analytics

This directory contains supporting analytical documents created for the academic modernization case study.

They cover infrastructure assessment, verification protocol material and efficiency calculations. They are supporting portfolio artifacts - not confidential corporate records and not independent vendor benchmarks.

The full bachelor thesis is intentionally **not** published in this repository.

## Economic model

The reconciled public business-case calculation is documented in [`ECONOMIC_MODEL.md`](./ECONOMIC_MODEL.md).

The public model uses the explicit operating-cost inputs from the project materials:

- traditional annual OPEX: **€430,000**;
- optimized annual OPEX: **€262,000**;
- calculated OPEX saving: **€168,000/year**;
- calculated OPEX reduction: **39.1% (~40% rounded)**;
- avoided-loss assumption: **€247,000/year**;
- reconciled gross annual economic effect: **€415,000/year**.

With an implementation-investment range of **€180,000–€220,000**, the same model gives a simple full-effect payback of approximately **0.43–0.53 years** and a simple first-year ROI of approximately **88.6%–130.6%**.

The defense-material values `€422,000/year`, `28% ROI` and `1.4 years` remain preserved as **legacy thesis-reported figures** because the public inputs do not reproduce them under one consistent formula set.

Headline business values should only be repeated in the README when their assumptions are stated clearly and internally consistent.
