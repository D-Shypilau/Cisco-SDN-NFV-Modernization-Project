# EVE-NG Laboratory

This directory contains the exported EVE-NG snapshot used as the practical Cisco SD-WAN laboratory for the portfolio.

## Included

- `NetCore_SDN_Project.unl` - EVE-NG topology definition.
- `topology.png` - visual topology snapshot.

## Important

The `.unl` file is the current laboratory snapshot and is the primary reference for what is actually present in the published EVE-NG topology. The wider bachelor-thesis design includes additional technologies that are not all represented as running nodes in this export.

Cisco virtual appliance images are proprietary and are **not** included. To reproduce the lab, provide appropriately licensed images in your own EVE-NG installation.

Before treating a result as reproducible, see [`../../docs/IMPLEMENTATION_STATUS.md`](../../docs/IMPLEMENTATION_STATUS.md).
